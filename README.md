### ⚡ Executive Summary

I am a **Systems & Applied AI Engineer** based in Bangalore, pursuing Computer Science at BMSCE. I specialize in designing and shipping production-grade platforms with deep architectural emphasis on **autonomous multi-agent orchestration, verifiable LLM pipelines, resource-constrained edge systems, and low-latency mobile/web applications**.

Rather than treating AI as a black-box text generator, I build **deterministic, tool-augmented systems**: implementing verification loops to eliminate hallucinations, embedding multi-spectral spatial telemetry into inference pipelines, running stochastic Monte Carlo simulations, and isolating multi-tenant services at the kernel level.

### 🧠 Applied AI, Agentic Workflows & System Internals

```
 ┌───────────────────────────────────┐     ┌───────────────────────────────────┐     ┌───────────────────────────────────┐
 │   Deterministic Tool Execution    │ ──► │     Verifier Gatekeeper Loop      │ ──► │    Kernel & Edge Orchestration    │
 │ Multi-agent schemas, Gemini JSON  │     │ Dual-pass verification preventing │     │ cgroups & namespaces on 4GB edge  │
 │ Mode & Ollama function calling    │     │ hallucinations in ledger state    │     │ nodes; zero-drain native C++ sync │
 └───────────────────────────────────┘     └───────────────────────────────────┘     └───────────────────────────────────┘
```

- **Autonomous Agentic Orchestration & Verification:** Engineered multi-brain agent workflows in [Finora](https://github.com/sharancode3/Finora) utilizing tool-calling schemas with local LLMs (Ollama) and cloud APIs (Gemini). Developed a dedicated `Verifier` agent pattern that inspects tool calls and ledger modifications to mathematically validate financial outputs prior to state committal.
- **Strict Schema-Constrained Inference:** Built end-to-end structured evaluation engines in [Skill-Lens AI](https://github.com/sharancode3/Skill-lens-AI) using JSON Schema enforcement for turn-by-turn skill taxonomy parsing, semantic code telemetry, and deterministic scoring.
- **Multi-Spectral Spatial Telemetry & Automated Reporting:** Designed end-to-end ingestion pipelines in [ThermoTrace AI](https://github.com/sharancode3/ThermoTrace-AI) for SIH 2026, processing thermal satellite bands, calculating spatial anomaly clusters, and generating synthesized compliance reports.
- **Resource-Aware Edge Engineering:** Designed [Homelab BaaS](https://github.com/sharancode3/Homelab), a self-hosted developer platform running multi-tenant isolated services, container orchestration, and relational database provisioning on single-node 4 GB RAM edge hardware.
- **Low-Overhead Native Telemetry:** Architected [GiGly](https://github.com/sharancode3/GiGly) using Flutter and a custom native C++/Kotlin bridge for continuous background telemetry without degrading device battery life.
